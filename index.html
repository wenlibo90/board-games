// QUICK START

一行代码快速接入

无需构建、无需依赖，只需引用一行 <script>标签，棋盘自动出现在脚本所在处；没写皮肤，就直接渲染原始棋牌。

index.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>棋牌 Demo</title>
</head>
<body>
<script src="https://cdn.jsdelivr.net/gh/wenlibo90/board-games@v0.2.0/sdk/arena.js"></script>
</body>
</html>
可选参数：game 棋种（默认 xiangqi）· size 路数 · side 执子方 · difficulty AI 难度 · theme 主题 两种写法等价：arena.js?game=gomoku 或 data-arena="gomoku"
自定义皮肤：Arena.mount / Arena.create
